# 📋 Your Tasks

A simple and elegant **task management app** built with **React Native** and **Firebase**, designed to help users manage their daily tasks efficiently.

---

## 🚀 Features

- 🔐 **Authentication**
  - Email & password registration/login
  - Update username and password
  - Secure logout
- ✅ **Task Management**
  - Create, edit, and delete tasks
  - Set deadlines with date picker
  - Mark tasks as complete
- 👤 **User Profile**
  - Save and edit username
  - View tasks specific to the logged-in user
- ⚙️ **Settings**
  - Edit account info
  - Logout button
- 🎨 **Modern UI**
  - Clean and user-friendly interface
  - Responsive layout for all devices

---

## 🛠️ Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Firebase](https://firebase.google.com/)
  - Authentication
  - Firestore (Database)
- [React Navigation](https://reactnavigation.org/)
- [Expo DateTimePicker](https://docs.expo.dev/versions/latest/sdk/datetimepicker/)
